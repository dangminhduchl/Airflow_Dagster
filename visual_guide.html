💡 Giải thích: Dagster không quản lý chuỗi task; nó quản lý Tài sản Dữ liệu (Assets). Di chuột vào code bên trái để xem cách Dagster tự động vẽ Data Lineage!

🌪️ Cách Airflow Nối Các Task

Trong code của bạn: branch_choice >> skipped_result >> finish

1. Dùng toán tử >> (Bitwise Shift) để khai báo thứ tự trước sau.

2. Luân chuyển dữ liệu: Task 1 return cái gì thì bị Worker chạy lệnh SQL:
INSERT INTO xcom (val) VALUES ('{"orders": ...}')
nhét vào Database PostgreSQL.

3. Task 2 muốn nhận dữ liệu phải gọi ngầm ti.xcom_pull() để kéo từ Database ra!
⚠️ Hạn chế: Nối dây là "mù dữ liệu". Airflow chỉ biết Task B chạy sau Task A, chứ không kiểm tra xem Task A có trả về đúng kiểu dữ liệu Task B cần hay không.

⚡ Cách Dagster Nối Các Asset

Trong code của bạn: def validated_orders(raw_orders_batch):

1. HOÀN TOÀN KHÔNG DÙNG TOÁN TỬ >>.

2. Dagster đọc tên tham số: Thấy hàm validated_orders có đối số raw_orders_batch trùng với tên Asset 1.

3. Luân chuyển dữ liệu: IOManager tự động cất đối tượng vào MinIO/Disk. Đến lượt Asset 2, IOManager tự nạp file vào tham số hàm!
🌟 Ưu thế vượt trội: Type-safe 100%! Đồ thị phụ thuộc dữ liệu (Data Lineage) sinh ra tự nhiên, chuẩn Software Engineering.

Tính Năng / Nghiệp Vụ Apache Airflow Dagster Bản Chất Vì Sao
Vẽ Sơ Đồ Graph View Bạn phải tự cấu hình (viết toán tử >>) Framework tự lo (đọc tên tham số hàm) Dagster quản lý dữ liệu (Asset-Centric) nên tự hiểu quan hệ cha-con. Airflow chỉ quản lý thứ tự task.
Lưu & Chuyển Dữ Liệu Lớn (Ảnh, DataFrame) Bạn phải tự viết code upload S3 Framework tự lo qua IOManager XCom của Airflow ép vào Postgres. IOManager của Dagster được thiết kế từ đầu cho Object Storage.
Chống Lỗi Skip Khi Rẽ Nhánh (Choice State) Bạn phải nhớ cấu hình trigger_rule Framework tự lo (tự hiểu nhánh bỏ qua) Airflow mặc định coi upstream không chạy là lỗi hoặc skip. Dagster hỗ trợ Multi-Output tự nhiên.
Xem Preview Dữ Liệu & Chỉ Số Trên Web Không hỗ trợ sẵn (chỉ có log đen trắng) Framework tự lo khi truyền metadata={...} Dagster có sẵn Asset Catalog, hiểu được con số doanh thu, số dòng, độ tin cậy.
Chạy Test Pytest Nhanh Trong 1.9s Cực khó (phải mock cả cụm database) Framework tự lo (hàm execute_in_process) Hàm của Dagster là hàm Python thuần túy. Hàm của Airflow bị bọc chặt vào runtime của cluster.
